# 🤖 Sassy Number Guessing Game

A Python-based command-line game that challenges players to guess a secret number. It features live state tracking, restricted logic loops, and a built-in "attitude" generator that gives sarcastic feedback for incorrect guesses.

## ✨ Features

*   🎯 **Smart Range Logic:** Generates a random target number between 1 and 100.
*   🏆 **Live Score Tracking:** Dynamically updates your current streak and session high scores.
*   💬 **Sassy Commentary:** Custom conditional responses that roast poor mathematical guesses.
*   🛡️ **Input Validation:** Safely handles letters, symbols, or empty spaces without crashing the script.

## 🛠️ Tech Stack & Concepts Used

*   **Language:** Python
*   **Core Logic:** While loops, nested If-Else statements, and conditional expressions.
